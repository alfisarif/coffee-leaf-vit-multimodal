# Dataset Description

The final experiment contains 840 paired observations linking a coffee leaf image, three agro-environmental measurements (relative humidity, soil moisture, and soil pH), and a canonical disease label. The four canonical classes are Leaf spot, Coffee rust, Sooty mold, and Healthy.

Original class counts: Leaf spot 253, Coffee rust 242, Sooty mold 195, Healthy 150.

The final split contains 672 original training observations and 168 source-separated validation observations. The validation set contains 46 unique image sources. Training-only sensor augmentation expands the training side to 2,016 effective entries.
